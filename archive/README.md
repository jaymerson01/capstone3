# Archive (old versions — not used by the current app)

These folders are earlier versions of ResQ, kept for reference only.
The live app is in `../clean_folder`.

| Folder | What it was | Why it's archived |
|---|---|---|
| `main_folder/` | First Flutter prototype (hardcoded data, demo admin login) | Replaced by `clean_folder` |
| `community_safety_app/` | Second version on a Node + PostgreSQL backend (local PC only) | Team moved to Firebase in `clean_folder` |
| `backend/` | Node/Express + Prisma + PostgreSQL API for `community_safety_app` | Not used by `clean_folder` |
| `test-automation-lab/` | Selenium tests written for the older web version | Targets the old app; needs rewriting for `clean_folder` |
| `notes/` | Old team notes, a sample commit file, a UI diff, an outdated readiness report | History only |

Everything here is also in the git history, so it is safe to delete this
folder later once the whole team agrees.
